# Giotto: Intelligence you control

Giotto is a Swiss AI research lab building sovereign AI. Founded in Lausanne in 2017 by EPFL mathematicians, we build a growing family of efficient reasoning models that run in our European cloud, on a dedicated cloud, or fully on-premise.

Our reasoning approach ranked 2nd on the ARC-AGI 2025 public leaderboard, among ~1.5k teams. We're GDPR-aligned and ISO/IEC 27001:2022 certified, and we never train on customer data.

## Research

The repos in this organization cover our ARC-AGI work:


 - [giotto-arc-agi-model](https://github.com/giotto-ai/giotto-arc-agi-model): an encoder-decoder model tuned on ARC-AGI.
 - [giotto-arc-agi-data](https://github.com/giotto-ai/giotto-arc-agi-data): scripts for accessing the dataset.

## Topological machine learning

We also maintain open-source libraries for topological machine learning, still used by a large research community:

 - [giotto-tda](https://github.com/giotto-ai/giotto-tda): topological data analysis (docs)
 - [giotto-ph](https://github.com/giotto-ai/giotto-ph): persistent homology
 - [giotto-deep](https://github.com/giotto-ai/giotto-deep): topological deep learning
